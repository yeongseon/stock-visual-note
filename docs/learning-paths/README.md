# 학습 경로 (Learning Paths)

레벨별 용어를 주제에 맞게 묶어 순서대로 학습할 수 있는 가이드입니다.

## 예정 경로

### 1. 주식 입문 코스 (Level 1-2)
주식·주가·시가총액부터 매수·매도·체결까지, 주식 거래를 시작하기 위한 기본 용어.

### 2. 재무제표 읽기 코스 (Level 3-4)
매출액·영업이익·순이익의 차이를 이해하고, ROE·부채비율 등 핵심 지표를 해석하는 법.

### 3. 밸류에이션 코스 (Level 5)
PER·PBR·EV/EBITDA를 사용해 기업이 비싼지 싼지 판단하는 프레임워크.

### 4. 이벤트 대응 코스 (Level 6-7)
배당·유상증자·전환사채 등 기업 이벤트가 주가에 미치는 영향 이해.

### 5. 실적 분석 코스 (Level 8-9)
컨센서스·어닝서프라이즈·사이클을 이해하고 실적 시즌에 대응하는 법.

### 6. 기업분석 종합 코스 (Level 10)
안전마진·투자 아이디어·포트폴리오 구성까지, 실전 기업분석 프레임워크.

---

> 각 코스의 상세 커리큘럼은 추후 개별 파일로 작성됩니다.
