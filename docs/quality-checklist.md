# 품질 체크리스트

## 발행 전 필수 확인

### SEO

- [ ] 핵심 용어가 제목 앞부분에 있는가?
- [ ] 본문 첫 200자 안에 핵심 키워드가 자연스럽게 포함되어 있는가?
- [ ] SEO 메타 설명이 작성되어 있는가?
- [ ] Tistory 태그가 정리되어 있는가?
- [ ] 중복 키워드 남용이 없는가?

### 콘텐츠 구조

- [ ] 한 줄 정의가 명확한가?
- [ ] 초보자도 이해할 쉬운 설명이 있는가?
- [ ] 숫자 예시가 있는가?
- [ ] 다이어그램이 있는가?
- [ ] 표가 있는가?
- [ ] 초보자가 자주 하는 오해를 짚었는가?
- [ ] 고수의 관점을 설명했는가?
- [ ] 기업분석에서 쓰는 법을 연결했는가?

### 내부 링크

- [ ] 함께 보면 좋은 용어가 3~5개 이상 있는가?
- [ ] 링크가 실제 발행된 글과 연결되는가?

### 컴플라이언스

- [ ] 투자 권유처럼 보이는 표현이 없는가?
- [ ] "무조건", "반드시", "확실한" 등 단정적 표현이 없는가?
- [ ] 목표가나 매수·매도 의견이 없는가?
- [ ] 글 하단에 교육 목적 안내 문구가 있는가?

### 메타데이터

- [ ] frontmatter의 category, topic, level, tags가 정확한가?
- [ ] status가 "review"에서 "published"로 변경 준비가 되었는가?
- [ ] last_reviewed 날짜가 오늘인가?

## 제목 패턴 참고

### 용어 설명형
- `{용어} 뜻, 주식 초보가 반드시 알아야 하는 이유`

### 오해 교정형
- `{용어}이 낮으면 무조건 좋은 주식일까?`

### 비교형
- `{A}과 {B} 차이, 주식 초보도 쉽게 이해하기`

### 기업분석 연결형
- `기업분석에서 {용어}을 보는 법`
