# 품질 점수 시스템 (Quality Score)

## 개요

각 글의 품질을 0~100점으로 산정하는 기준입니다. 현재는 수동 체크리스트로 운영하며, 자동 점수 산정은 추후 구현 예정입니다.

## 점수 산정 기준

| 항목 | 배점 | 기준 |
|------|------|------|
| 필수 섹션 완성 | 24점 | 12섹션 × 2점 |
| 다이어그램 품질 | 10점 | 코드블록 존재(5) + 3줄 이상(5) |
| 표 포함 | 10점 | 마크다운 테이블 존재(5) + 3행 이상(5) |
| 숫자 예시 | 10점 | "숫자로 보는 예시" 섹션에 숫자 존재(5) + 가상예시 표시(5) |
| 내부 링크 | 10점 | 3개 이상(5) + 모두 유효(5) |
| 면책 조항 | 5점 | 통일 형식 존재 |
| Tags 일치 | 5점 | frontmatter tags = footer Tags |
| SEO 필드 | 10점 | seo_title(3) + description ≤120자(3) + primary_keyword(2) + search_intent(2) |
| 금지 표현 없음 | 6점 | 금지 표현 0개(6), 1개당 -2점 |
| frontmatter 완성 | 10점 | 필수 필드 모두 존재(10) |
| **합계** | **100점** | |

## 등급

| 점수 | 등급 | 의미 |
|------|------|------|
| 90-100 | A | 발행 가능 |
| 70-89 | B | 소규모 수정 후 발행 |
| 50-69 | C | 주요 수정 필요 |
| 0-49 | D | 재작성 필요 |

## 사용법

```bash
# 전체 검증
python3 scripts/validate.py

# 특정 파일 검증
python3 scripts/validate.py content/.../per.md

# 엄격 모드 (경고도 에러 처리)
python3 scripts/validate.py --strict
```

## 발행 기준

- **A 등급 (90점 이상)**: status → published 가능
- **B 등급 이하**: review_status를 "needs_review"로 유지
