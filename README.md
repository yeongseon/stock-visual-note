# stock-terms-visual-blog

**주식 초보가 용어를 이해하고, 그 용어로 실제 기업을 분석할 수 있게 만드는 그림과 표 중심의 한국어 투자 학습 블로그.**

## 포지셔닝

> 용어 하나를 이해하면, 기업 하나를 더 잘 볼 수 있습니다.

## 구조

```
content/stock-terms/ko/
├── level-01-basic/              # 주식 기본 언어 (40개)
├── level-02-market-trading/     # 시장과 거래 (50개)
├── level-03-financial-statements/ # 재무제표 기초 (70개)
├── level-04-ratios/             # 수익성·안정성 지표 (60개)
├── level-05-valuation/          # 밸류에이션 (60개)
├── level-06-events/             # 공시·자본 이벤트 (70개)
├── level-07-earnings/           # 실적·컨센서스 (50개)
├── level-08-industry-macro/     # 산업·매크로 (60개)
├── level-09-strategy-risk/      # 투자전략·리스크 (50개)
└── level-10-company-analysis/   # 기업분석 실전 (50개)
```

## 템플릿

- `templates/term-post-template.md` — 용어 설명 글 표준 템플릿
- `templates/company-analysis-template.md` — 기업분석 글 표준 템플릿

## 글 작성 흐름

1. 용어 선정 → 2. 검색 의도 확인 → 3. 개요 작성 → 4. 쉬운 설명 → 5. 숫자 예시 → 6. 다이어그램 → 7. 표 → 8. 오해 섹션 → 9. 고수 관점 → 10. 기업분석 연결 → 11. 내부 링크 → 12. SEO 확인 → 13. 발행

## 목표

| 단계 | 글 수 | 기간 |
|---|---|---|
| MVP | 50개 | 4~8주 |
| 2차 | 100개 | 2~3개월 |
| 3차 | 200개 | 4~6개월 |
| 최종 | 400~500개 | 12개월+ |

## 채널

- 1차: Tistory 한국어 블로그
- 확장: 전자책, 뉴스레터, 노션 템플릿, 강의, 웹서비스

## 원칙

- 투자 권유 금지. 교육 목적만.
- 초등학생도 이해할 수 있는 첫 설명.
- 모든 글에 다이어그램 + 표 필수.
- 용어에서 시작해 기업분석으로 연결.
