# 마진 개선 뜻 — 매출 대비 이익 비율이 높아지는 것

## 한 줄 정의

마진 개선은 기업의 이익률(영업이익률, 순이익률 등)이 이전보다 높아지는 현상입니다.

## 아주 쉽게 말하면

100원 매출에서 이전에는 10원 남기던 것을 이제 15원 남기게 되었다는 것입니다. 같은 매출이라도 더 많이 벌 수 있게 된 것입니다.

## 왜 중요한가

- 마진 개선은 이익 성장의 "질"이 좋아지고 있다는 신호입니다
- 매출 성장 없이도 마진 개선만으로 이익이 크게 증가할 수 있습니다
- 지속적 마진 개선은 밸류에이션 멀티플 상향(리레이팅)의 근거입니다
- 마진 개선 원인(구조적 vs 일시적)에 따라 지속 가능성이 다릅니다

## 그림으로 이해하기

```
┌─── 마진 개선 효과 ────────────────────────┐
│                                            │
│  매출 1,000억 (동일)                       │
│                                            │
│  ┌── 전 분기 ──┐   ┌── 이번 분기 ──┐     │
│  │ 원가 700억   │   │ 원가 650억     │     │
│  │ 판관비 200억 │   │ 판관비 200억   │     │
│  │ 영업이익     │   │ 영업이익       │     │
│  │   100억      │   │   150억        │     │
│  │ (마진 10%)   │   │ (마진 15%)     │     │
│  └─────────────┘   └───────────────┘     │
│                                            │
│  마진 +5%p → 이익 +50% 증가!             │
└────────────────────────────────────────────┘
```

## 숫자로 보는 예시

> ⚠️ 아래 숫자는 개념 설명을 위한 **가상 예시**이며, 실제 투자 데이터가 아닙니다.

O기업 영업이익률 추이:

- 1Q: 8% → 2Q: 10% → 3Q: 12% → 4Q: 14%
- 매출이 분기당 1,000억으로 동일해도:
  - 1Q 영업이익: 80억 → 4Q 영업이익: 140억
  - 이익 증가율: +75% (매출 성장 0%인데!)

이것이 "이익 레버리지" 효과입니다.

## 표로 비교하기

| 마진 개선 원인 | 지속 가능성 | 주가 반응 |
|--------------|-----------|----------|
| 제품 믹스 개선 (고마진 제품 비중 ↑) | 높음 | 강한 긍정 |
| 고정비 레버리지 (매출 증가) | 중간 | 긍정 |
| 원자재 가격 하락 | 낮음 (외부 요인) | 제한적 |
| 구조조정·인력 감축 | 중간 | 단기 긍정 |
| 환율 효과 | 낮음 (변동성) | 제한적 |

## 초보자가 자주 하는 오해

**오해 1: "매출이 안 늘면 성장이 없는 것이다"**

마진 개선만으로도 이익은 큰 폭으로 증가할 수 있습니다. 매출 성장 + 마진 개선이 동시에 나타나면 이익이 폭발적으로 늘어납니다.

**오해 2: "마진이 한번 개선되면 계속 유지된다"**

원자재 가격 변동, 경쟁 심화 등으로 마진이 다시 악화될 수 있습니다. 개선 원인의 구조적 여부를 확인해야 합니다.

## 고수는 이렇게 봅니다

- 마진 개선 원인을 매출총이익률·판관비율로 분해합니다
- 동종업체 대비 마진 수준을 비교하여 추가 개선 여지를 판단합니다
- "매출 성장 + 마진 개선"이 동시에 나타나는 기업에 최고 점수를 줍니다
- 마진 개선이 3분기 연속이면 구조적 변화로 판단합니다

## 기업분석에서는 이렇게 씁니다

- 분기별 영업이익률 추이를 그래프로 만들어 방향을 확인합니다
- 마진 개선 원인(원가 vs 판관비 vs 믹스)을 분해하여 지속성을 평가합니다
- 목표 영업이익률을 설정하여 적정 이익과 주가를 산출합니다

## 정리

마진 개선은 매출 대비 이익 비율이 높아지는 것으로, 이익 성장의 질을 나타냅니다. 매출 성장 없이도 마진 개선만으로 이익이 큰 폭으로 증가할 수 있으며, 개선 원인이 구조적인지 일시적인지를 판단하는 것이 핵심입니다.

## 한 줄 요약

> 마진 개선은 이익률이 높아지는 것이며, 매출 성장 없이도 이익을 크게 늘릴 수 있는 핵심 동력입니다.
