# 모멘텀 뜻 — 주가를 움직이는 힘 또는 계기

## 한 줄 정의

모멘텀은 주가가 특정 방향으로 움직이게 하는 동력이나 계기를 의미합니다.

## 아주 쉽게 말하면

"이 주식이 오를 이유"입니다. 실적 개선, 신제품 출시, 정책 변화 등 주가를 밀어올리는(또는 끌어내리는) 힘을 모멘텀이라고 합니다.

## 왜 중요한가

- 모멘텀이 있는 종목은 추세적으로 상승/하락합니다
- 실적 모멘텀은 가장 강력하고 지속적인 주가 동력입니다
- 모멘텀 소멸 시점을 감지하면 매도 타이밍을 잡을 수 있습니다
- "좋은 기업 + 모멘텀"이 갖춰져야 주가가 움직입니다

## 그림으로 이해하기

```
┌─── 모멘텀 유형 ───────────────────────────┐
│                                            │
│  ① 실적 모멘텀                             │
│     컨센서스 상향, 어닝서프라이즈 연속      │
│     → 가장 강력, 지속 기간 길음            │
│                                            │
│  ② 이벤트 모멘텀                           │
│     신제품, M&A, 정책 수혜                  │
│     → 단기 강력, 지속성 확인 필요          │
│                                            │
│  ③ 수급 모멘텀                             │
│     외국인·기관 매수 전환                   │
│     → 추세 확인 역할                       │
│                                            │
│  ④ 기술적 모멘텀                           │
│     신고가, 이동평균 돌파                   │
│     → 보조 지표                            │
└────────────────────────────────────────────┘
```

## 숫자로 보는 예시

L기업의 모멘텀 분석:

- 3개월 전: 컨센서스 영업이익 500억 → 현재 700억 (상향 +40%)
- 외국인 순매수: 20거래일 연속
- 주가: 3개월 전 30,000원 → 현재 42,000원 (+40%)
- 신규 모멘텀: AI 관련 신사업 진출 발표

실적 모멘텀 + 이벤트 모멘텀이 겹치며 강한 상승세.

## 표로 비교하기

| 모멘텀 유형 | 지속 기간 | 강도 | 예시 |
|------------|----------|------|------|
| 실적 모멘텀 | 3~12개월 | 매우 강함 | 연속 서프라이즈 |
| 산업 모멘텀 | 6~24개월 | 강함 | 업황 회복, 정책 |
| 이벤트 모멘텀 | 1~4주 | 중간 | 신제품, 수주 |
| 수급 모멘텀 | 2~8주 | 중간 | 기관 매집 |
| 기술적 모멘텀 | 1~4주 | 약함 | 차트 돌파 |

## 초보자가 자주 하는 오해

**오해 1: "모멘텀 투자 = 묻지마 추격 매수"**

모멘텀 투자는 "왜 오르는지" 이유를 알고 투자하는 것입니다. 이유 없이 오르는 것을 쫓으면 고점에 물립니다.

**오해 2: "좋은 회사면 모멘텀 없어도 오른다"**

아무리 좋은 기업이라도 주가를 움직일 계기(모멘텀)가 없으면 장기 횡보합니다.

## 고수는 이렇게 봅니다

- 실적 모멘텀(컨센서스 상향 추이)을 최우선으로 봅니다
- 모멘텀의 "강도×지속성"으로 포지션 크기를 결정합니다
- 모멘텀 소멸 신호(컨센서스 상향 정체, 가이던스 하향)를 감시합니다
- 여러 모멘텀이 겹치는 종목을 최우선 후보로 봅니다

## 기업분석에서는 이렇게 씁니다

- 투자 아이디어의 "왜 지금?"에 해당하는 것이 모멘텀입니다
- 모멘텀의 시작 시점과 예상 지속 기간을 명시합니다
- 모멘텀 소멸 조건을 미리 정의하여 매도 기준으로 활용합니다

## 정리

모멘텀은 주가를 움직이는 힘이며, 실적 모멘텀이 가장 강력하고 지속적입니다. "좋은 기업 + 모멘텀"이 갖춰져야 주가가 움직이며, 모멘텀 소멸 시점을 감지하는 것이 매도 타이밍의 핵심입니다.

## 한 줄 요약

> 모멘텀은 주가를 움직이는 계기이며, 실적 모멘텀이 가장 강력하고 지속 가능한 동력입니다.
