# 기업분석 프레임워크(Company Analysis Framework) — 체계적으로 투자 판단에 도달하는 5단계

## 한 줄 정의

기업분석 프레임워크는 하나의 기업을 체계적으로 평가하기 위해 정해진 순서와 항목으로 분석하는 구조화된 방법론입니다.

## 아주 쉽게 말하면

여행 가기 전 체크리스트를 만드는 것과 같습니다. 여권, 호텔, 교통, 환전, 일정 — 순서대로 체크하면 빠뜨리는 것이 없습니다. 기업분석도 "사업 → 산업 → 재무 → 가치 → 판단" 순서로 따라가면, 감에 의존하지 않고도 논리적인 투자 결론에 도달할 수 있습니다. 체크리스트가 있으면 초보자도 프로와 같은 관점을 가질 수 있습니다.

## 왜 중요한가

- 감이 아닌 구조로 판단하여 일관성을 유지합니다
- 모든 기업에 동일한 기준을 적용할 수 있어 비교가 가능합니다
- 빠뜨리기 쉬운 리스크(지배구조, 산업 쇠퇴)를 사전에 점검합니다
- 분석 결과를 축적하면 패턴 인식 능력이 복리로 성장합니다
- 팀 내 커뮤니케이션 시 공통 언어와 기준을 제공합니다

## 숫자로 보는 예시

> ⚠️ 아래 숫자는 개념 설명을 위한 **가상 예시**이며, 실제 투자 데이터가 아닙니다.

가상 기업 '스마트물류' 5단계 분석 요약:

| 단계 | 핵심 질문 | 분석 결과 | 판정 |
|------|-----------|-----------|------|
| 1. 사업 이해 | 어떻게 돈을 버는가? | 물류 자동화 로봇 판매 60%, 유지보수 40% | ✓ 반복매출 비중 높음 |
| 2. 산업 분석 | 시장이 성장하는가? | 물류 자동화 시장 연 22% 성장 전망 | ✓ 고성장 산업 |
| 3. 재무 분석 | 숫자가 뒷받침하는가? | 매출 +35%/년, 영업이익률 18%, 순현금 | ✓ 재무 건전 |
| 4. 밸류에이션 | 현재 가격이 적정한가? | PER 18배 (업종 25배), 안전마진 28% | ✓ 할인 매수 가능 |
| 5. 투자 판단 | 매수할 것인가? | 투자 아이디어: "물류 자동화 수요 급증 수혜" | ✓ 매수 결정 |

5단계 모두 통과 → 투자 실행. 한 단계라도 탈락(Kill) → 다음 종목으로.

## 표로 비교하기

| 구분 | 프레임워크 사용 | 프레임워크 없음 |
|------|----------------|----------------|
| 분석 범위 | 전체 (사업→산업→재무→가치→판단) | 부분적·편향적 |
| 소요 시간 | 체계적 → 2~3시간이면 완료 | 산만 → 며칠 걸려도 결론 못 냄 |
| 비교 가능성 | 기업 간 동일 기준 적용 | 기업마다 다른 기준 |
| 리스크 발견 | 체크리스트로 조기 포착 | 놓치기 쉬움 |
| 학습 효과 | 분석할수록 패턴 축적 | 매번 처음부터 |
| 감정 개입 | 구조가 감정 차단 | 뉴스·테마에 흔들림 |

## 초보자가 자주 하는 오해

**오해 1: "재무제표만 보면 기업분석이다"**

숫자는 과거입니다. 사업 모델과 산업 전망을 먼저 이해해야 숫자의 의미를 해석할 수 있습니다. "왜 이 숫자가 나왔는가"를 알려면 Step 1~2가 선행되어야 합니다.

**오해 2: "분석을 완벽하게 해야 투자할 수 있다"**

완벽한 분석은 불가능합니다. 핵심 가설 2~3개를 검증하고, 불확실성은 안전마진·포지션 크기·분할매수로 관리합니다. "80% 확신"이면 실행하고 나머지는 시장에서 검증받습니다.

**오해 3: "프레임워크는 전문가만 쓰는 것이다"**

오히려 초보자에게 더 필요합니다. 경험이 부족할수록 체계가 감을 대신해줍니다. 프레임워크를 따라가다 보면 자연스럽게 분석 실력이 쌓입니다.

## 고수는 이렇게 봅니다

- 5단계를 30분 안에 빠르게 훑는 "스크리닝"과 수 시간의 "딥다이브"를 구분합니다
- 각 단계에 Kill criteria(탈락 조건)를 설정하여 시간을 절약합니다 (예: ROE 5% 미만 → 탈락)
- 분석 결과를 노션/엑셀에 기록하고 실적 발표마다 업데이트합니다
- 같은 산업의 여러 기업을 동시에 분석하여 상대 비교합니다
- 1년 후 실제 결과와 자신의 분석을 복기하여 오류 패턴을 찾습니다

## 기업분석에서는 이렇게 씁니다

이 프레임워크 자체가 기업분석의 전체 지도입니다:

| 단계 | 핵심 질문 | 주요 도구 | Kill 조건 예시 |
|------|-----------|-----------|--------------|
| 사업 이해 | 이 회사는 어떻게 돈을 버는가? | 사업보고서, IR | 사업 모델 이해 불가 |
| 산업 분석 | 시장은 커지고 있는가? | 산업 리포트, 경쟁사 | 시장 축소·과당 경쟁 |
| 재무 분석 | 실적이 가설을 뒷받침하는가? | 재무제표, ROE, FCF | 3년 연속 적자·부채 과다 |
| 밸류에이션 | 지금 가격이 적정한가? | PER, PBR, DCF | 안전마진 15% 미만 |
| 투자 판단 | 얼마에 사고, 언제 팔 것인가? | 투자 아이디어, 손절 | 명확한 가설 수립 불가 |

## 정리

기업분석 프레임워크는 "사업 → 산업 → 재무 → 밸류에이션 → 투자 판단"의 5단계로 기업을 체계적으로 평가하는 도구입니다. 이 순서를 따르면 초보자도 논리적이고 일관된 투자 판단에 도달할 수 있으며, 분석 경험이 쌓일수록 패턴 인식 능력이 향상되어 더 빠르고 정확한 판단이 가능해집니다.

## 한 줄 요약

> 기업분석 프레임워크는 "이 회사에 투자해도 되나?"를 5단계 체크리스트로 답하는 구조화된 방법입니다.
