# 블록딜 뜻 — 대량의 주식을 한꺼번에 거래하는 것

## 한 줄 정의

블록딜은 대규모 주식 물량을 장외 또는 시간외에서 한 번에 매매하는 거래 방식입니다.

## 아주 쉽게 말하면

"대주주가 100만 주를 팔고 싶은데, 장중에 내놓으면 주가가 폭락할 수 있으니 따로 조용히 파는 것"입니다. 보통 증권사가 중개합니다.

## 왜 중요한가

- 블록딜은 대량 물량이 시장에 나왔다는 의미로 단기 하락 요인입니다
- 할인율(보통 2~10%)이 크면 매수자에게 유리하지만 기존 주주에게는 부담입니다
- 보호예수 해제 후 대주주·기관이 블록딜로 지분을 정리하는 경우가 많습니다
- 거래 성사 여부와 소화 속도가 시장 심리에 큰 영향을 줍니다

## 그림으로 이해하기

```
┌─── 블록딜 프로세스 ───────────────────────┐
│                                            │
│  매도자(대주주)                             │
│       │                                    │
│       ▼  매도 의뢰                         │
│  증권사(주관사)                             │
│       │                                    │
│       ▼  할인가 제시 (종가 대비 -5%)       │
│  기관투자자 A, B, C... (매수 참여)         │
│       │                                    │
│       ▼  시간외 대량매매 체결              │
│  다음 날 장 시작 → 시장 반응               │
│                                            │
│  성공: 물량 소화 → 오버행 해소             │
│  실패: 미소화 물량 → 추가 하락 압력       │
└────────────────────────────────────────────┘
```

## 숫자로 보는 예시

F기업 대주주가 블록딜로 200만 주를 매도합니다.

- 전일 종가: 50,000원
- 블록딜 할인율: 5%
- 블록딜 체결가: 47,500원
- 총 거래 규모: 950억 원
- 기존 유통주식: 2,000만 주 → 거래 물량 비율 10%

다음 날 주가가 47,500원 근처로 하락하는 것이 일반적입니다.

## 표로 비교하기

| 항목 | 블록딜 | 장내 대량 매도 |
|------|--------|---------------|
| 거래 방식 | 시간외·장외 협의 | 장중 호가 매도 |
| 시장 충격 | 상대적으로 작음 | 매우 큼 |
| 할인율 | 2~10% | 없음 (시장가) |
| 체결 속도 | 1일 내 일괄 | 수일~수주 소요 |
| 투명성 | 공시 후 확인 | 실시간 확인 |

## 초보자가 자주 하는 오해

**오해 1: "블록딜이면 회사에 문제가 있다"**

매도 사유는 다양합니다. 펀드 만기, 포트폴리오 리밸런싱, 상속세 납부 등 회사 자체 문제와 무관한 경우가 많습니다.

**오해 2: "블록딜 할인율만큼 무조건 주가가 빠진다"**

매수 기관이 빠르게 소화하면 주가는 단기 조정 후 회복됩니다. 기업 펀더멘털이 좋으면 할인 매수 기회가 되기도 합니다.

## 고수는 이렇게 봅니다

- 블록딜 규모 대비 일평균 거래대금을 비교하여 소화 가능성을 판단합니다
- 매도자가 누구인지(최대주주 vs PE펀드 vs 기관)에 따라 의미가 다릅니다
- 할인율이 과도하게 높으면(10%+) 급한 매도 → 부정적 신호로 봅니다
- 블록딜 후 2~3일 내 주가 회복 여부로 수요 강도를 확인합니다

## 기업분석에서는 이렇게 씁니다

- 블록딜 후 잔여 보호예수 물량을 재계산하여 추가 오버행을 측정합니다
- 블록딜 매수자(전략적 투자자인지)에 따라 긍정적 해석이 가능합니다
- 블록딜 이력이 잦은 종목은 수급 불안정 리스크를 할인율에 반영합니다

## 정리

블록딜은 대량 주식을 시간외·장외에서 할인가로 한꺼번에 매매하는 방식입니다. 장내 매도 시 주가 충격을 줄이기 위해 사용하며, 블록딜 소식 후 단기 주가 하락은 흔합니다. 매도 사유와 소화 속도를 확인하는 것이 핵심입니다.

## 한 줄 요약

> 블록딜은 대량 주식을 할인가에 일괄 매도하는 거래이며, 단기 주가 하락 요인이 됩니다.
