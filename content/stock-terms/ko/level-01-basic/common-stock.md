# 보통주 뜻, 일반 주주가 보유하는 주식

주식 앱에서 "삼성전자"와 "삼성전자우"가 따로 있는 걸 본 적 있나요?

"삼성전자"가 보통주이고, "삼성전자우"가 우선주입니다. 대부분의 투자자가 사고파는 주식은 보통주입니다.

## 한 줄 정의

보통주는 의결권과 배당권을 모두 가진 가장 일반적인 형태의 주식입니다.

## 아주 쉽게 말하면

동아리에서 모든 회원에게 투표권이 있는 것과 같습니다. 보통주를 가진 주주는 회사의 중요한 결정에 투표할 수 있고, 이익이 나면 배당도 받을 수 있습니다.

주식시장에서 별도 표시 없이 거래되는 주식은 대부분 보통주입니다.

## 왜 중요한가

- 보통주 주주는 주주총회에서 의결권을 행사할 수 있습니다 (이사 선임, 배당 결정 등).
- 회사가 청산될 때 잔여 재산을 받을 권리가 있습니다 (다만 우선주보다 후순위).
- 대부분의 주식 거래는 보통주로 이루어지므로 유동성이 높습니다.
- 기업 지배구조를 이해하려면 보통주와 우선주의 차이를 알아야 합니다.

## 그림으로 이해하기

```
┌────────────────────────────────────┐

│                                    │
│  ┌──────────┐    ┌──────────┐      │
│  │ 의결권    │    │ 배당받을  │      │
│  │          │    │ 권리     │      │
│  │ 주주총회  │    │          │      │
│  │ 투표 참여 │    │ 이익 배분 │      │
│  └──────────┘    └──────────┘      │
│        │               │          │
│        └───────┬───────┘          │
│                ▼                   │
│  ┌──────────────────────┐         │
│  │  잔여재산 분배 청구권  │         │
│  │  (회사 청산 시)       │         │
│  └──────────────────────┘         │
│                                    │
│  ※ 세 가지 모두 보통주에 있음       │
└────────────────────────────────────┘
```

_보통주는 의결권, 배당권, 잔여재산 분배 청구권을 모두 가집니다._

## 숫자로 보는 예시

A회사가 보통주 1,000만 주를 발행했고, 내가 1만 주를 가지고 있다면:

- 내 지분율 = 1만 ÷ 1,000만 = **0.1%**
- 주주총회에서 0.1%의 투표권 행사 가능
- 배당 총액이 100억 원이면 내 몫 = **100만 원** (100억 × 0.1%)
- 의결권 1만 표로 이사 선임 등에 참여 가능

## 표로 비교하기

| 구분 | 보통주 | 우선주 |
|---|---|---|
| 의결권 | 있음 | 없거나 제한적 |
| 배당 우선순위 | 후순위 | 선순위 |
| 배당률 | 회사 결정에 따름 | 보통주보다 높은 경우 많음 |
| 주가 | 기준 가격 | 보통주보다 낮은 경우 많음 |
| 거래량 | 많음 (유동성 높음) | 적음 (유동성 낮음) |
| 종목명 표시 | "삼성전자" | "삼성전자우" |

## 초보자가 자주 하는 오해

**오해 1: 보통주와 우선주는 같은 회사니까 주가도 같다**

같은 회사의 주식이지만 권리가 다르므로 가격도 다릅니다. 우선주는 의결권이 없는 대신 배당이 유리한 경우가 많아, 보통주보다 10~30% 정도 낮게 거래되는 경우가 일반적입니다 (괴리율).

**오해 2: 개인 투자자의 의결권은 의미 없다**

소액 주주 1명의 표는 적지만, 개인 투자자 전체가 모이면 상당한 영향력이 됩니다. 최근에는 주주활동(주주제안, 의결권 행사)이 활발해지면서 소액 주주의 목소리도 커지고 있습니다.

## 고수는 이렇게 봅니다

숙련된 투자자는 보통주와 우선주의 괴리율을 관찰합니다.

- 괴리율이 역사적으로 높으면 → 우선주가 상대적으로 저평가일 수 있음
- 지배구조 이슈가 있는 회사는 → 보통주의 의결권 프리미엄이 높아짐
- 합병·인수 이벤트 시 → 보통주와 우선주의 합병 비율이 쟁점이 됨

## 기업분석에서는 이렇게 씁니다

기업분석에서 보통주는 시가총액 계산의 기본입니다.

- 시가총액 = 보통주 주가 × 보통주 발행 수 + 우선주 주가 × 우선주 발행 수
- EPS, BPS 등 주당 지표는 보통주 기준으로 계산합니다.
- 최대주주의 보통주 지분율이 경영권 안정성의 핵심 지표입니다.

## 정리

- 보통주는 의결권과 배당권을 모두 가진 가장 일반적인 주식이다.
- 주식시장에서 기본으로 거래되는 것은 보통주이다.
- 우선주와 가격 차이(괴리율)가 있으며, 이것도 투자 판단의 재료가 된다.

## 한 줄 요약

보통주는 의결권과 배당권을 모두 가진 표준 주식이며, 대부분의 주식 거래는 보통주로 이루어집니다.
