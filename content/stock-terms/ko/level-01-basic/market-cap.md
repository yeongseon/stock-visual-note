# 시가총액 뜻, 주가보다 먼저 봐야 하는 이유

"이 회사 주가가 5만 원이니까 삼성전자보다 싸네?" 이런 생각을 해본 적이 있다면, 시가총액을 반드시 이해해야 합니다.

시가총액은 시장이 그 회사 전체에 매기는 가격입니다. 주가보다 훨씬 정확하게 회사의 크기를 보여줍니다.

## 한 줄 정의

시가총액은 주가 × 발행 주식 수로, 시장이 평가하는 회사 전체의 가격입니다.

## 아주 쉽게 말하면

피자 한 조각이 5,000원이고, 피자가 8조각이라면 피자 한 판 가격은 40,000원입니다.

주식도 마찬가지입니다. 1주 가격(주가)에 총 조각 수(발행 주식 수)를 곱하면 회사 전체의 시장 가격이 나옵니다. 이것이 시가총액입니다.

## 왜 중요한가

- 회사 규모를 정확히 비교할 수 있습니다. 주가만으로는 불가능합니다.
- 대형주, 중형주, 소형주를 구분하는 기준이 됩니다.
- 기업을 통째로 인수한다면 얼마가 필요한지 감을 잡을 수 있습니다.
- 코스피, 코스닥 지수에서 시가총액이 큰 종목일수록 영향력이 큽니다.

## 그림으로 이해하기

```
┌────────────────────────────────────────┐
│           시가총액 계산                  │
│                                        │
│   주가        ×    발행 주식 수         │
│                                        │
│  50,000원     ×    1억 주              │
│       │                │               │
│       └───────┬────────┘               │
│               ▼                        │
│        시가총액 = 5조 원                │
│                                        │
│  ┌──────────────────────────────┐      │
│  │ 회사 전체를 시장에서          │      │
│  │ 5조 원으로 평가하고 있다      │      │
│  └──────────────────────────────┘      │
└────────────────────────────────────────┘
```

_주가와 발행 주식 수를 곱하면 시장이 매기는 회사 전체 가격이 됩니다._

## 숫자로 보는 예시

| 회사 | 주가 | 발행 주식 수 | 시가총액 |
|---|---|---|---|
| A | 80만 원 | 600만 주 | 4.8조 원 |
| B | 5만 원 | 1억 주 | 5조 원 |
| C | 3,000원 | 20억 주 | 6조 원 |

주가 순서: A > B > C
회사 규모 순서: C > B > A

주가와 회사 규모는 완전히 다릅니다.

## 표로 비교하기

| 구분 | 시가총액 기준 | 예시 (한국 시장) | 특징 |
|---|---|---|---|
| 대형주 | 상위 100위 이내 | 삼성전자, SK하이닉스 | 안정적, 거래량 풍부 |
| 중형주 | 101~300위 | 중견기업 | 성장과 안정 사이 |
| 소형주 | 300위 밖 | 소규모 기업 | 변동성 크고, 정보 부족할 수 있음 |

## 초보자가 자주 하는 오해

**오해 1: 주가가 높으면 시가총액도 크다**

주가가 100만 원이어도 발행 주식 수가 1만 주면 시가총액은 100억 원에 불과합니다. 반대로 주가가 1,000원이어도 발행 주식 수가 100억 주면 시가총액은 10조 원입니다. 항상 곱셈으로 계산해야 합니다.

**오해 2: 시가총액이 크면 무조건 좋은 회사다**

시가총액은 시장의 "기대"가 반영된 가격입니다. 실적이 뒷받침되지 않는데 기대만으로 시가총액이 부풀어 있을 수도 있습니다. 크기가 크다고 투자에 유리한 것은 아닙니다.

## 고수는 이렇게 봅니다

숙련된 투자자는 시가총액을 "이 회사를 통째로 산다면 지불할 금액"으로 봅니다.

- 이 회사가 연간 1,000억 원을 버는데, 시가총액이 1조라면 10년 치 이익을 미리 지불하는 셈입니다.
- 동종 업계 다른 회사와 시가총액 대비 이익·매출을 비교하면 상대적 저평가·고평가를 판단할 수 있습니다.

## 기업분석에서는 이렇게 씁니다

기업분석에서 시가총액은 밸류에이션의 출발점입니다.

- PER = 시가총액 ÷ 순이익 → 이익 대비 얼마나 비싼가
- PBR = 시가총액 ÷ 순자산 → 자산 대비 얼마나 비싼가
- PSR = 시가총액 ÷ 매출 → 매출 대비 얼마나 비싼가

모든 비율 지표의 분자는 결국 시가총액(또는 주가)입니다. 시가총액을 모르면 밸류에이션을 할 수 없습니다.

## 정리

- 시가총액 = 주가 × 발행 주식 수 = 시장이 매기는 회사 전체 가격이다.
- 회사 규모를 비교하려면 주가가 아니라 시가총액을 봐야 한다.
- 밸류에이션 지표의 출발점이 시가총액이다.

## 한 줄 요약

시가총액은 시장이 매기는 회사 전체 가격이며, 회사 크기를 비교할 때 주가 대신 봐야 하는 숫자입니다.
