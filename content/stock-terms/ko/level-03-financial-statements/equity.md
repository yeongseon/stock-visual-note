# 자본 뜻 — 주주의 몫

## 한 줄 정의

자본은 기업의 총자산에서 부채를 뺀 나머지, 즉 주주에게 귀속되는 순자산입니다.

## 아주 쉽게 말하면

내가 3억짜리 집을 가지고 있는데 대출이 2억이면, 진짜 내 돈은 1억입니다. 기업도 마찬가지로 자산에서 빚을 빼면 주주의 진짜 몫인 '자본'이 나옵니다.

## 왜 중요한가

자본은 기업의 재무 체력을 보여줍니다. 자본이 꾸준히 늘어나면 기업이 이익을 축적하고 있다는 뜻이고, 자본이 줄어들면 적자가 누적되고 있다는 경고 신호입니다. PBR(주가순자산비율) 계산의 분모이기도 합니다.

## 그림으로 이해하기

```
┌────────────────────────────────────┐
│         자본의 구성 요소            │
├────────────────────────────────────┤
│                                    │
│  자본금 ─── 주주가 처음 넣은 돈    │
│     +                              │
│  자본잉여금 ─ 액면 초과 납입분     │
│     +                              │
│  이익잉여금 ─ 벌어서 쌓아 둔 돈    │
│     -                              │
│  자기주식 ─── 회사가 사들인 주식   │
│     =                              │
│  ★ 자본 총계 (= 순자산)           │
│                                    │
└────────────────────────────────────┘
```

## 숫자로 보는 예시

B기업 재무상태표:
- 자본금: 50억 원 (발행주식 × 액면가)
- 자본잉여금: 150억 원
- 이익잉여금: 700억 원
- 자기주식: -100억 원
- **자본 총계: 800억 원**
- 발행주식수: 1,000만 주
- BPS = 800억 ÷ 1,000만 = **8,000원/주**

## 표로 비교하기

| 구분 | 자본금 | 이익잉여금 | 자본잉여금 |
|------|--------|-----------|-----------|
| 원천 | 주주 납입 | 영업 이익 축적 | 주식발행초과금 등 |
| 변동 요인 | 유·무상증자 | 당기순이익, 배당 | 합병차익, 감자차익 |
| 투자자 관심 | 희석 여부 | 성장의 증거 | 일회성 여부 |
| 크기 비중 | 보통 작음 | 보통 가장 큼 | 중간 |

## 초보자가 자주 하는 오해

1. **"자본금이 크면 큰 회사다"**
   → 자본금은 액면가 × 주식수일 뿐, 기업 규모와 직결되지 않습니다. 삼성전자 자본금은 약 8,975억 원이지만, 이익잉여금은 수백조 원입니다.

2. **"자본이 마이너스일 수는 없다"**
   → 적자가 오래 누적되면 자본이 음수(자본잠식)가 됩니다. 완전 자본잠식이면 상장폐지 사유에 해당합니다.

## 고수는 이렇게 봅니다

숙련된 투자자는 이익잉여금의 추이를 봅니다. 매년 이익잉여금이 증가하면 기업이 벌어서 쌓고 있다는 뜻이고, 감소하면 배당 과다 지급이나 적자 전환을 의심합니다. 또한 자기주식 매입이 자본을 줄이더라도 주당 가치를 높이는 효과가 있어 긍정적으로 봅니다.

## 기업분석에서는 이렇게 씁니다

ROE(자기자본이익률)를 계산할 때 분모가 자본입니다. 자본이 너무 작으면 ROE가 비정상적으로 높게 나올 수 있어, 절대 금액과 비율을 함께 확인합니다. 또한 유상증자 공시가 나오면 자본 증가 → 주당 가치 희석 가능성을 분석합니다.

## 정리

자본은 자산에서 부채를 뺀 주주의 순수한 몫입니다. 자본금·이익잉여금·자본잉여금으로 구성되며, 이익잉여금의 꾸준한 증가가 건전한 성장의 핵심 신호입니다.

## 한 줄 요약

> 자본은 '주주의 진짜 몫'이며, 이익잉여금이 꾸준히 늘어나는 기업이 좋은 기업입니다.
