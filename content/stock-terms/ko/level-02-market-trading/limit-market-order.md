# 지정가와 시장가 차이, 주문 방식 쉽게 이해하기

주식을 사려고 주문 버튼을 누르면 "지정가"와 "시장가" 중 하나를 선택해야 합니다.

뭘 선택하느냐에 따라 체결 가격과 속도가 달라지므로, 차이를 정확히 알아야 합니다.

## 한 줄 정의

지정가는 내가 원하는 가격을 지정하는 주문, 시장가는 현재 시장 가격으로 즉시 체결하는 주문입니다.

## 아주 쉽게 말하면

- 지정가 = "이 가격이면 사겠습니다" (가격 확정, 체결 불확실)
- 시장가 = "당장 아무 가격이든 사겠습니다" (체결 확실, 가격 불확실)

마트에서 "사과가 3,000원 이하면 살게요"가 지정가, "지금 있는 사과 바로 주세요"가 시장가입니다.

## 왜 중요한가

- 지정가: 원하는 가격에 체결되지만, 해당 가격에 도달하지 않으면 체결이 안 됩니다.
- 시장가: 즉시 체결되지만, 급등·급락 시 예상보다 불리한 가격에 체결될 수 있습니다.
- 주문 방식 선택이 실질 수익률에 영향을 줍니다.

## 그림으로 이해하기

```
┌─────────────────────────────────────┐
│     지정가 vs 시장가 비교            │
│                                     │
│  [지정가 주문]                       │
│  "10,000원에 사겠습니다"             │
│                                     │
│  현재가 10,200원 → 체결 안 됨 (대기)│
│  현재가 10,000원 → 체결! ✓          │
│  현재가  9,800원 → 체결! ✓ (더 유리)│
│                                     │
│  ─────────────────────────────────  │
│                                     │
│  [시장가 주문]                       │
│  "지금 바로 사겠습니다"              │
│                                     │
│  현재 매도 1호가 10,100원            │
│  → 10,100원에 즉시 체결! ✓          │
│  (가격 선택 불가)                    │
└─────────────────────────────────────┘
```

_지정가는 가격을 내가 정하고, 시장가는 시장이 정합니다._

## 숫자로 보는 예시

> ⚠️ 아래 숫자는 개념 설명을 위한 **가상 예시**이며, 실제 투자 데이터가 아닙니다.

현재 A주식 호가 상황:
- 매도 1호가: 10,100원 (500주)
- 매도 2호가: 10,200원 (1,000주)

내가 2,000주를 사고 싶을 때:

**지정가 10,000원**: 현재가보다 낮으므로 체결 안 됨. 주가가 내려오길 기다림.

**시장가**: 500주는 10,100원, 나머지 1,500주는 10,200원에 체결. 평균 매수가 약 10,167원.

## 표로 비교하기

| 구분 | 지정가 | 시장가 |
|---|---|---|
| 가격 | 내가 정함 | 시장이 정함 |
| 체결 속도 | 느림 (미체결 가능) | 즉시 |
| 체결 확실성 | 불확실 | 확실 |
| 불리한 체결 | 없음 | 가능 (슬리피지) |
| 적합한 상황 | 급하지 않을 때, 가격 중요할 때 | 빠른 체결이 필요할 때 |
| 초보자 추천 | ✓ (가격 통제 가능) | △ (급등락 시 주의) |

## 초보자가 자주 하는 오해

**오해 1: 시장가가 항상 현재 보이는 가격에 체결된다**

시장가 주문은 "그 순간 가장 좋은 가격"에 체결됩니다. 주문 넣는 사이에 가격이 변할 수 있고, 수량이 많으면 여러 가격에 나뉘어 체결됩니다. 급등·급락 시 예상보다 크게 다른 가격에 체결될 수 있습니다.

**오해 2: 지정가를 걸어두면 반드시 체결된다**

주가가 내 지정 가격에 도달하지 않으면 영원히 체결되지 않습니다. 또한 같은 가격에 먼저 주문한 사람이 우선이므로 (시간 우선 원칙), 내 차례가 안 올 수도 있습니다.

## 고수는 이렇게 봅니다

숙련된 투자자는 상황에 따라 주문 방식을 다르게 씁니다.

- 평소 매매: 지정가 (0.1~0.3% 차이가 장기적으로 누적)
- 급등 종목 매도: 시장가 (빠져나가는 것이 가격보다 중요)
- 분할 매수: 여러 지정가를 단계적으로 설정
- 대형주: 시장가도 무방 (유동성 풍부)
- 소형주: 반드시 지정가 (스프레드가 넓어서)

## 기업분석에서는 이렇게 씁니다

기업분석과 직접 관련은 없지만, 분석 결과를 실행할 때:

- 분석으로 적정가를 산출했으면 → 적정가 이하에 지정가 매수 설정
- 장기 투자라면 → 현재가 부근 지정가로 빠르게 확보 (0.5% 차이보다 기업 가치가 중요)
- 긴급 매도 필요 시 (악재 발생) → 시장가로 빠르게 탈출

## 정리

- 지정가는 내가 원하는 가격을 정하는 주문 (체결 불확실, 가격 확정)이다.
- 시장가는 즉시 체결되는 주문 (체결 확실, 가격 불확실)이다.
- 초보자는 지정가를 기본으로 사용하고, 급할 때만 시장가를 쓰는 편이 실수를 줄일 수 있다.

## 한 줄 요약

지정가는 가격을 내가 정하고 체결을 기다리는 주문, 시장가는 즉시 체결되지만 가격을 시장에 맡기는 주문입니다.
