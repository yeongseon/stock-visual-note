# 호가 뜻, 주식을 사고파는 가격표 읽기

주식 앱에서 숫자가 빨간색, 파란색으로 빽빽하게 나열된 화면을 본 적 있나요?

그것이 호가창(주문창)입니다. 호가를 읽을 수 있으면 현재 매수·매도 세력의 힘 관계를 실시간으로 볼 수 있습니다.

## 한 줄 정의

호가는 주식을 사거나 팔겠다고 제시하는 가격과 수량입니다.

## 아주 쉽게 말하면

경매장에서 "1만 원에 사겠습니다!", "1만 1천 원에 팔겠습니다!" 하고 외치는 것과 같습니다.

사고 싶은 사람이 부르는 가격이 매수 호가, 팔고 싶은 사람이 부르는 가격이 매도 호가입니다. 이 모든 주문을 모아놓은 것이 호가창입니다.

## 왜 중요한가

- 현재 매수·매도 세력의 균형을 실시간으로 볼 수 있습니다.
- 내 주문이 어떤 가격에 체결될지 예측할 수 있습니다.
- 대량 매수·매도 벽(물량)을 보고 지지/저항 가격을 파악할 수 있습니다.
- 주문 방식(지정가, 시장가)을 결정하는 근거가 됩니다.

## 그림으로 이해하기

```
┌──────────────────────────────────┐
│          호가창 구조               │
│                                  │
│  매도 호가 (팔겠다는 주문)        │
│  ┌────────────────────────┐      │
│  │ 10,500원  │  2,000주   │ 5호가│
│  │ 10,400원  │  5,000주   │ 4호가│
│  │ 10,300원  │  8,000주   │ 3호가│
│  │ 10,200원  │  3,000주   │ 2호가│
│  │ 10,100원  │  1,500주   │ 1호가│
│  └────────────────────────┘      │
│  ════════════════════════════     │
│  현재가: 10,050원                 │
│  ════════════════════════════     │
│  ┌────────────────────────┐      │
│  │ 10,000원  │  4,000주   │ 1호가│
│  │  9,900원  │  2,500주   │ 2호가│
│  │  9,800원  │  6,000주   │ 3호가│
│  │  9,700원  │  1,000주   │ 4호가│
│  │  9,600원  │  3,000주   │ 5호가│
│  └────────────────────────┘      │
│  매수 호가 (사겠다는 주문)        │
└──────────────────────────────────┘
```

_위쪽이 매도 호가(팔려는 물량), 아래쪽이 매수 호가(사려는 물량)입니다._

## 숫자로 보는 예시

위 호가창에서:
- 시장가로 즉시 매수하면 → 10,100원에 체결 (매도 1호가)
- 시장가로 즉시 매도하면 → 10,000원에 체결 (매수 1호가)
- 스프레드(매수·매도 차이) = 10,100 - 10,000 = **100원** (약 1%)

매도 3호가에 8,000주가 쌓여 있으면, 10,300원이 단기 저항선 역할을 할 수 있습니다.

## 표로 비교하기

| 호가창 신호 | 의미 | 해석 |
|---|---|---|
| 매수 물량 >> 매도 물량 | 사려는 힘이 강함 | 단기 상승 가능성 |
| 매도 물량 >> 매수 물량 | 팔려는 힘이 강함 | 단기 하락 가능성 |
| 특정 가격에 대량 매도 | 매도 벽 (저항) | 해당 가격 돌파 어려울 수 있음 |
| 특정 가격에 대량 매수 | 매수 벽 (지지) | 해당 가격 아래로 내리기 어려울 수 있음 |
| 스프레드가 넓음 | 유동성 부족 | 거래 비용 증가 |

## 초보자가 자주 하는 오해

**오해 1: 호가창의 물량은 반드시 체결된다**

호가창에 보이는 물량은 "주문"이지 "체결"이 아닙니다. 주문은 언제든 취소할 수 있습니다. 대량 매수 주문을 걸어놓고 가격이 오르면 취소하는 "허수 주문"도 존재합니다.

**오해 2: 호가창만 보면 주가 방향을 알 수 있다**

호가창은 "현재" 주문 상태일 뿐, 1초 뒤에 대량 주문이 들어오거나 취소될 수 있습니다. 참고 도구로만 활용해야 하며, 호가창만으로 매매를 결정하면 위험합니다.

## 고수는 이렇게 봅니다

숙련된 투자자는 호가창을 다음 용도로 활용합니다.

- 내 주문의 체결 가격을 최적화 (지정가 설정)
- 대량 물량의 출현·소멸 패턴 관찰
- 유동성이 충분한지 확인 (큰 금액 매매 시)
- 단, 중장기 투자에서는 호가창보다 기업 가치에 집중

## 기업분석에서는 이렇게 씁니다

기업분석 자체에서 호가를 분석하지는 않지만, 실전 매매에서:

- 분석이 끝나고 실제 매수할 때, 호가 스프레드를 확인해 매매 비용 최소화
- 거래량이 적은 종목은 스프레드가 넓어 분석에서 좋아 보여도 실제 매매 비용이 클 수 있음
- 대형주는 스프레드가 좁아 분석 결과를 바로 실행하기 쉬움

## 정리

- 호가는 사거나 팔겠다고 제시하는 가격과 수량이다.
- 호가창에서 매수·매도 세력의 힘 관계를 실시간으로 볼 수 있다.
- 호가창의 물량은 주문이지 확정이 아니므로, 참고 도구로만 활용해야 한다.

## 한 줄 요약

호가는 주식을 사고팔겠다고 제시하는 가격이며, 호가창을 통해 현재 매수·매도 세력의 힘 관계를 확인할 수 있습니다.
